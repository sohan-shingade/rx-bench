Benchmark

A Benchmark for Medical AI Voice Agents

Voice agents launder uncertainty into the medical record: a mumbled drug name, a mis-heard dose, or a confidently wrong confirmation becomes a clean-looking chart entry. This benchmark evaluates what actually lands in the record — 111 tasks across 8 suites, with FHIR-verified outcomes, reliability measured as pass^k over repeated i.i.d. trials, and dedicated safety scorers for the failure modes that matter in a clinic. It scores the chart, not the conversation.

The first domain covers medical front-office phone workflows (scheduling, refills, messages, identity verification, escalation); emergency-department intake, symptom triage, and post-discharge follow-up are on the domain roadmap. The benchmark's motivating application is the development of an ED intake agent.

How agents are scored

Outcomes are verified against the FHIR record produced by each episode, not against transcripts. Reliability is reported as pass^k: the probability that an agent succeeds on all k of k i.i.d. trials of a task.

pass^k = Etask[ C(c, k) / C(n, k) ]   (n trials per task, c successes)
  • Safety scorers: false-confirmation rate, provenance violations, LASA substitution rate, readback rate.
  • Infrastructure: built on Sierra’s τ²-bench framework and the τ-voice full-duplex stack (MIT license).
  • Meta-evaluation: policy mutation testing and vacuity checking guard against tasks that pass for the wrong reasons.

Agent classes

Results are reported per agent class so that text scaffolds, audio-native models, and ASR pipelines are never compared apples-to-oranges.

A

Text · standard scaffold

The agent operates over text with the benchmark’s standard tool scaffold. Isolates policy and reasoning quality from the audio channel.

B

Voice · audio-native

A single audio-native model handles the full-duplex conversation end to end — no intermediate transcript to hide behind.

C

Voice · pipeline (ASR→LLM→TTS)

A composed stack of speech recognition, a text model, and speech synthesis — the dominant production architecture today.
